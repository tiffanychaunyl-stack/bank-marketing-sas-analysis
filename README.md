# Bank Marketing Analysis — SAS Studio

## Project Overview

This project analyzes a bank marketing dataset using SAS Studio to identify patterns and factors associated with customer responses to marketing campaigns. The analysis focuses on data exploration, statistical relationships, and predictive modeling to better understand customer behavior.

## Tools & Technologies

* SAS Studio
* Data Exploration
* Statistical Analysis
* Predictive Modeling
* Data Visualization

## Key Analysis

* Explored customer demographic and campaign-related variables.
* Examined relationships between customer characteristics and marketing outcomes.
* Prepared and analyzed data using SAS Studio.
* Applied predictive modeling techniques to evaluate factors associated with customer responses.
* Interpreted analytical results and summarized key findings.

## Skills Demonstrated

* Data analysis using SAS Studio
* Data cleaning and exploration
* Statistical interpretation
* Predictive analytics
* Business-focused interpretation of analytical results
